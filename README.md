# Corner-Grocer

## 1. Summarize the project and what problem it was solving.

The Corner Grocer project was a C++ program designed to help a grocery store track how often different items were purchased. The program reads a list of purchased items from a file, counts how many times each item appears, and allows the user to view the results. Users can search for a specific item, view a list of all items and their purchase frequencies, or display a histogram. The goal was to make it easier for the store to understand purchasing patterns and manage inventory.

## 2. What did you do particularly well?

I think I did a good job organizing the program into different functions and using a class to manage the grocery items. Separating the different tasks into functions made the code easier to follow. Using the GroceryItem class helped keep the item names and quantities organized in one place, making the program easier to manage and update.

## 3. Where could you enhance your code? How would these improvements make your code more efficient, secure, and so on?

One improvement I could make would be improving how the program handles missing files and unexpected user input. Although I included some basic error handling, there is still room to make the program more reliable. 

## 4. Which pieces of the code did you find most challenging to write, and how did you overcome this? What tools or resources are you adding to your support network?

One of the more challenging parts was understanding how the map worked with the GroceryItem class and pointers. I had to figure out how to store the grocery items, update their quantities, and manage memory correctly. I worked through the program one section at a time and tested the different functions to identify problems. I also became more comfortable using Visual Studio, debugging, and the course materials to troubleshoot issues.

## 5. What skills from this project will be particularly transferable to other projects or course work?

Some of the most useful skills I gained were working with classes, functions, maps, file input and output, and debugging. I also gained more experience organizing a larger program instead of writing everything inside the main function. I think these skills will be useful in future programming courses, especially when working on larger projects that require more organization.

## 6. How did you make this program maintainable, readable, and adaptable?

I tried to keep the program organized by separating different tasks into functions and using descriptive names for variables and functions. I also included comments to help explain what different sections of the code were doing. Using a class for the grocery items helped keep related information together. This organization should make it easier to update the program or add new features in the future.
